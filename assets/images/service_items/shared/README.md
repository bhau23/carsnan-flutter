# Shared Service Item Images

This folder contains shared images for service items that can be used across all service categories (General, Premium, Luxury).

## Available Images:

✅ `foam_wash.jpg` - Foam washing equipment or process
✅ `interior_vacuum.jpg` - Interior vacuuming equipment
✅ `exterior_rinse.jpg` - Exterior rinsing process
✅ `tire_cleaning.jpg` - Tire cleaning process
✅ `dashboard_wipe.jpg` - Dashboard cleaning
✅ `seat_cleaning.jpg` - Seat cleaning process
✅ `glass_cleaning.jpg` - Window/glass cleaning
✅ `air_freshener.jpg` - Air freshener application
✅ `wheel_polish.jpg` - Wheel polishing process
✅ `leather_conditioning.jpg` - Leather conditioning treatment
✅ `carpet_shampoo.jpg` - Carpet shampooing process
✅ `engine_cleaning.jpg` - Engine bay cleaning
✅ `wax_application.jpg` - Car wax application
✅ `underbody_wash.jpg` - Underbody washing

## Image Requirements:
- Format: JPG (preferred) or PNG
- Recommended size: 300x200 pixels
- High quality images showing the actual service process
- Consistent lighting and style across all images

## Usage:
These images are automatically mapped to service items based on their names in the ServiceItemCard widget. Each service item name is converted to snake_case and mapped to the corresponding image file.
